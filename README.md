# CHXS — Pollo que cruje

Web interactiva basada en CHXS_Pitch_Interactivo_v2.pptx. HTML, CSS y JavaScript sin dependencias de ejecución.

## Ejecutar

Desde `/workspace/Tin`:

```sh
python -m http.server 3000 --bind 0.0.0.0
```

Abrir el servidor en un navegador. También puede abrirse `index.html` directamente. Para publicar, subir `index.html`, `style.css`, `app.js` y `assets/` a cualquier hosting estático.

Incluye transiciones al hacer scroll, navegación por secciones, simulador de contribución, criterios desplegables, diseño móvil y modo de movimiento reducido. Las tipografías de Google Fonts son opcionales y tienen alternativas locales.

Las imágenes son conceptos extraídos del PPTX. Se conserva la distinción entre datos del caso, supuestos del equipo y metas de desarrollo. El formato propuesto es de 50 g; el envase conceptual ilustrado indica 30 g, discrepancia informada en la página.
